### Proyectos Destacados

- **[Diseño de Red para LinkLabs](https://github.com/NinjaTechniques/linklabs_network)**  
  Diseñamos una nueva topología de red para la empresa ficticia LinkLabs, aplicando los modelos OSI y TCP/IP para mejorar el rendimiento y la escalabilidad. Trabajo colaborativo enfocado en optimizar la eficiencia de la red.

- **[Base de Datos para Reparaciones Técnicas](https://github.com/yasperht/security_repair)**  
  Lideré el diseño de una base de datos para la gestión de servicios de reparación de dispositivos electrónicos. Incluyó el modelo entidad-relación (Vertabelo) y su implementación física en SQL Server, desarrollando scripts para consultas y creación de tablas. Proyecto realizado en equipo.

- **[Aplicación Móvil para Estudiantes](https://github.com/Aplicaciones-Moviles-WV61-FlexiDorm/Student-Mobile-App)**  
  Creamos una aplicación en Flutter para facilitar a estudiantes la búsqueda de alquileres cerca de universidades y ayudar a arrendadores a gestionar alquileres a corto y largo plazo. Desarrollo realizado en equipo con enfoque en la usabilidad.

- **[Backend para MathPlayOpen](https://github.com/FundamentosDeArquitecturaWV72Grupo1/mathplayopen-backend)**  
  Lideré un equipo para desarrollar una plataforma de aprendizaje para estudiantes de secundaria, con funciones como juegos, rankings y reseñas para motivar el aprendizaje. Utilizamos SCRUM como metodología ágil y tecnologías modernas como Angular (frontend) y Spring Boot (backend). Trabajo completamente colaborativo.
